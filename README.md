# 🚗 Rota Fácil · Simmel Design

App para entregadores: fotografe as etiquetas, e o app monta a melhor rota a partir do seu ponto de partida.

**Abrir o app:** https://edersimmel.github.io/rota-facil-app/

No Chrome do Android: toque em **Instalar app** (ou ⋮ → Adicionar à tela inicial).
No iPhone (Safari): Compartilhar → **Adicionar à Tela de Início**.

Para ativar, escolha um plano na tela inicial do app e envie pelo WhatsApp.
